# MCP setup reference

Читай этот файл только когда необходимый MCP недоступен в текущей сессии. Сначала определи активный харнес; не выбирай адаптер только потому, что соответствующий CLI установлен на машине.

## Каталог серверов

| Источник | ID | Transport | Endpoint | Auth |
|---|---|---|---|---|
| Mobbin | `mobbin` | Streamable HTTP | `https://api.mobbin.com/mcp` | OAuth; нужен Mobbin Pro, Team или Enterprise |
| One Page Love | `onepagelove` | Streamable HTTP | `https://api.onepagelove.com/mcp` | Не требуется |
| Landing.Gallery | `landing-gallery` | Streamable HTTP | `https://www.landing.gallery/api/mcp` | Не требуется |
| VASA Works | `vasa-works` | Streamable HTTP | `https://mcp.vasa.works/mcp` | OAuth или ключ аккаунта; зависит от клиента |

Funded, Alexander Jarvis и Deck.gallery не являются MCP-серверами в этой конфигурации. Не пытайся устанавливать их как MCP.

## Общий порядок

1. Проверь доступные инструменты текущей сессии.
2. Проверь конфигурацию активного харнеса.
3. Если сервер отсутствует, запроси разрешение на установку.
4. Добавь только нужный сервер, используя endpoint из каталога.
5. Если нужна OAuth-авторизация, передай управление пользователю и дождись её завершения.
6. Проверь состояние сервера и сделай минимальный тестовый вызов.
7. Если инструмент не появился в текущем каталоге, попроси reload или restart и остановись.

## Codex

Проверка:

```sh
codex mcp list
codex mcp get <id> --json
```

Установка удалённого HTTP-сервера:

```sh
codex mcp add <id> --url <endpoint>
```

OAuth, если требуется:

```sh
codex mcp login <id>
```

После установки повторно проверь `codex mcp list`. Если MCP-инструменты не появились в активной сессии, попроси перезапустить клиент или начать новую сессию, сохранив исходную задачу.

## Claude Code

Проверка:

```sh
claude mcp list
claude mcp get <id>
```

Установка в локальный scope текущего проекта:

```sh
claude mcp add --transport http <id> <endpoint>
```

Не выбирай `--scope project` или `--scope user` без явного запроса: project меняет репозиторий через `.mcp.json`, user влияет на все проекты пользователя.

Для OAuth открой `/mcp` в интерактивной сессии Claude Code и попроси пользователя завершить браузерную авторизацию. Если сервер уже настроен, но выключен или ожидает approval, исправь состояние через `/mcp`, а не добавляй дубликат.

## Pi

В ядре Pi нет MCP. Сначала проверь, установлен ли MCP-adapter. Если нет, после разрешения пользователя установи адаптер:

```sh
pi install npm:@piarium/pi-mcp-adapter
```

Для unmodified upstream Pi допустима альтернатива `npm:pi-mcp-adapter`; не выбирай вариант, пока не определена установленная сборка Pi.

Адаптер читает стандартный `.mcp.json` проекта или `~/.config/mcp/mcp.json`. Перед созданием или изменением файла запроси разрешение и сохрани существующие записи. Минимальная запись удалённого сервера:

```json
{
  "mcpServers": {
    "<id>": {
      "type": "http",
      "url": "<endpoint>"
    }
  }
}
```

После установки адаптера попроси перезапустить Pi. Затем проверь сервер через интерфейс адаптера и выполни минимальный вызов.

## Другой или неизвестный харнес

- Сначала ищи нативный список инструментов, tool search или MCP status UI.
- Если клиент документирует импорт `.mcp.json`, используй запись выше только после разрешения пользователя.
- Если способ установки не установлен достоверно, не угадывай пути и команды. Передай пользователю `id`, transport, endpoint и требования авторизации из каталога.
- Если харнес вообще не поддерживает MCP, предложи ручной веб-доступ к источнику вместо скрытой замены другим инструментом.

## Проверка после подключения

Минимальный тест должен быть дешёвым и не запускать полноценное исследование:

- Mobbin: один узкий поиск с лимитом 1.
- One Page Love: один узкий поиск с лимитом 1 и без тяжёлой загрузки изображений, если параметр поддерживается.
- Landing.Gallery: один `search_inspiration` без `get_website`.
- VASA Works: запросить доступные категории или один результат в `slide-decks`.

Успешная запись в конфигурацию без успешного тестового вызова означает только «настроено», а не «готово к работе».
