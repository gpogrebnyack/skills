# Слоты в шаблоне

Слот — текстовый слой, который заполняет агент. Имя слота начинается с `#`.
Слой без `#` — декорация: агент его не трогает, проверка «остался шаблонный текст» его не смотрит.

| Имя | Что это |
|---|---|
| `#title` | главный заголовок слайда |
| `#lead` | лид под заголовком |
| `#value` | число-герой вне карточек |
| `#label` | подпись над `#value` |
| `#num` | номер раздела: 01 |
| `#head`, `#head-2`, `#head-3` | заголовки колонок таблицы (`#head-3` — на 95) |
| `#note` | сноска, подпись мелким кеглем |
| `#text`, `#text-2` | прочий одиночный текст |
| `#items` | контейнер повторяемых элементов (карточки, колонки, шаги, строки) |
| `#item` | один элемент внутри `#items` |
| `#item/num` | порядковый номер: 01, 02 |
| `#item/label` | мелкая надпись над элементом |
| `#item/title` | подзаголовок элемента |
| `#item/value` | крупное число элемента |
| `#item/text` | описание элемента |

Правила:
- Число элементов не меняют: при удалении или добавлении получается вёрстка, которой нет в шаблоне. Слайд подбирают под число пунктов.
- Внутри `#item` имена повторяются в каждом элементе — агент заполняет их по порядку.
- Если на слайде два набора элементов, второй называется `#items-2`, его элементы — `#item`.
- Внутри инстансов (Footer) слоты не размечаются: футер управляется свойствами компонента.

Лимиты в каталоге:
- Ширина и кегль — из шаблона. Число строк — из шаблонного текста, поэтому у коротких образцов лимит занижен.
- Лимит не ниже длины шаблонного текста: он заведомо влезает.
- Текст с ручными переносами в шаблоне стоит узкой стопкой, а лимит считается на всю ширину. Ориентир — длина образца.
- Окончательно влезание проверяет `deck verify` в Figma.
