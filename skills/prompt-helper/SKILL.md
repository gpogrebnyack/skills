# Prompt Helper

Один вход для промптов ко всем генеративным моделям. Гайд по каждой лежит
в `references/`, читай только нужный.

## Шаг 0. Проверка версий

Первым делом запусти `python3 scripts/check_updates.py` из папки навыка.

- Молчит — работай дальше.
- Напечатал строки `NEW …` — вышло что-то новое. Найди официальный гайд по
  промптингу для этой версии (сайт модели, документация API), обнови
  соответствующий файл в `references/`, поправь `scripts/versions.json`
  и одной строкой скажи пользователю, что обновил. Потом делай его задачу.
- Напечатал `ERROR …` — сеть недоступна, работай по текущим гайдам, не жди.

## Шаг 1. Определи модель

| Признак в запросе | Модель | Гайд |
|---|---|---|
| видео, ролик, кадр движется, «Клинг», мультишот, @персонаж | Kling 3.0 Omni | `references/kling-3-omni.md` |
| видео 30 секунд, со звуком, много референсов, монтаж, «Сидэнс» | Seedance 2.5 | `references/seedance-2.5.md` |
| картинка, иллюстрация, стикер, правка фото, «банана», Gemini | Nano Banana 2 / Pro | `references/nano-banana.md` |
| картинка с точным текстом, макет интерфейса, логотип, схема, «GPT», ChatGPT | GPT Image 2.5 | `references/gpt-image-2.5.md` |

Модель названа — бери её. Не названа и признаки не разводят —
задай **один** вопрос: «Это картинка или видео, и куда пойдёт?»
Дальше не переспрашивай, выбирай сам и назови выбор в ответе.

## Шаг 2. Собери промпт по гайду

Открой один файл из `references/`, следуй его структуре и запретам.
Общие правила для всех моделей:

- Промпт на английском, если пользователь не попросил иначе.
- Описывай сцену предложениями, не списком тегов.
- Конкретика вместо оценок: не «красивый свет», а «low warm side light, long shadows».
- Что должно остаться неизменным — говори явно.
- Не выдумывай возможности модели, которых нет в гайде.

## Шаг 3. Ответ

1. Готовый промпт в кодовом блоке — чтобы скопировать одним движением.
2. Одна-две строки: какую модель выбрал и почему, какие допущения сделал.
3. Если у модели есть настройки вне промпта (соотношение сторон, разрешение,
   длительность, quality) — назови рекомендуемые отдельной строкой.

Без вступлений и пересказа правил гайда.
